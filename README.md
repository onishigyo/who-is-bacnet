# Who-Is BACnet?

ビル設備の制御プロトコル **BACnet** が、**同じネットワークにいるだけで認証なしに操作できてしまう**という事実を、1 枚のネットワーク図の上で体験する学習教材です。後半では、その答えである **BACnet/SC** がどう防ぐかまでを扱います。別のテーマとして、ルータで分かれたネットワークの向こうにある機器を探す仕組み（**BBMD**）も扱います。ブラウザだけで動きます。

## 学ぶテーマ

画面上部の「学ぶテーマ」で切り替えます。

### BACnet の危険性と、その対策

危険性から入りません。まず対象を理解してから、その足元にある落とし穴を見せます。1 枚の図を育て、途中でそこへ攻撃者が現れます。

**IP**

1. **BACnet とは** ── 設備機器が同じ言葉で会話するための共通語
2. **BACnet/IP とは** ── その言葉を、ふだんの IP ネットワークの上で話せるようにしたもの
3. **便利な側面** ── 中央監視と機器の会話を、意訳と実コマンドの二層で再生する
4. **危険性** ── 同じネットワークに現れた PC が、まったく同じ言葉で割り込む

**SC**

5. **BACnet/SC とは** ── 証明書を持つ機器だけが、ハブを通して暗号化された会話をする
6. **危険性は防げるか** ── 同じ PC がハブに繋ごうとして、証明書がなく断られる
7. **SC の限界** ── SC に対応していない機器や、証明書の運用など、残る課題

### ルータの向こうの機器を探す方法

ネットワークがルータで 2 つに分かれた建物を、条件を変えて見比べます。

- **BBMD なし** ── 機器を探す呼びかけ（ブロードキャスト）はルータで止まり、向こう側の機器が見つからない
- **BBMD あり** ── BBMD が呼びかけを 1 対 1 の通信で運び直し、向こう側に配り直す
- **BACnet/SC なら** ── ハブが全員に配るので、BBMD が要らない

## 大事な前提

- **実際の BACnet 通信は発生しません。** このアプリはブラウザ内で完結する再現です。バックエンドを持ちません。
- **防御を学ぶための教材です。** 許可のないシステムへの操作を推奨するものではありません。
- **制作者はこの分野の専門家ではありません。** 学んだ内容を教材としてまとめたものであり、誤りを含む可能性があります。規格で確立している事柄と、制作者の理解・要検証の事柄は、本文中でバッジによって区別しています（「規格・公式資料に書いてある」／「制作者の理解（要検証）」）。誤りを見つけたら Issue で指摘してください。

パッケージマネージャは pnpm。

```bash
pnpm install
pnpm dev           # Vite dev サーバ
pnpm build         # 型チェック → バンドル
pnpm preview       # ビルド結果を確認（http://localhost:4173/）
pnpm lint          # ESLint
pnpm format:check  # Prettier（CI と同じ）
pnpm test          # Vitest
```

| ----------------- | ----------------------------------------------------------------------------------------------------------------- |
| `src/domain/`     | 型定義のみ                                                                                                        |

## Wireshark の答え合わせ

ステップ4（BACnet/IP）とステップ6（BACnet/SC）の答え合わせは、制作者が閉域の実験環境で取得したキャプチャです。`src/content/captures.ts` に、tshark で表示フィルタをかけて出力した行を**そのまま**持っています（Info 欄の空白の数も含めて手を加えない）。

- BACnet/IP: 表示フィルタ `bacnet`。持ち込まれた PC が機器を探し、設定温度を読んで書き換える記録
- BACnet/SC: 表示フィルタ `tcp.port==47900`。証明書を持たない PC が SC ハブに繋ごうとして、断られる記録

**元の pcapng はリポジトリに置きません。** 実験と無関係な通信（SSH・mDNS・DHCP など）や、個人を特定しうる情報が含まれるためです。公開するのは、上のフィルタで絞った範囲だけです。載せるアドレスが実験の閉域網のものだけであること、プロトコルがフィルタどおりであることはテストで確かめています。

同じ範囲を Wireshark で表示したスクリーンショットを添えたい場合は、`src/assets/captures/` に置いて該当エントリの `imageSrc` に渡してください（表示側の変更は不要）。秘密鍵・証明書（`*.key` / `*.pem` / `certs/`）はコミットしません（`.gitignore` 済み）。
